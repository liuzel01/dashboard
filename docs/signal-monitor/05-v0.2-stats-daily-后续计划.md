# Signal Monitor v0.2 统计与日报改造计划（后续实施）

> 状态：**计划中（不在当前迭代实施）**

## 1. 背景

当前 Realtime / History 已接入 v0.2 明细字段；
但 Stats / Daily 页面仍主要基于旧汇总口径（trigger/emitted/suppressed）。

为形成完整 v0.2 观察闭环，后续需补齐 v0.2 专项统计与日报视图。

## 2. 目标

- 在 Stats 页面补充 v0.2 指标卡与分布视图
- 在 Daily 页面补充 v0.2 日报摘要
- 保持旧统计口径可回看，避免一次性断层

## 3. 后端需求（计划）

建议在 `price-alert` 新增或扩展以下输出：

1. v0.2 总览
- `v02_emit_count`
- `v02_emit_rate`
- `v02_direction_breakdown`（bullish/bearish/neutral）
- `v02_confidence_breakdown`（low/medium/high）

2. v0.1 vs v0.2 对照
- `v01_emit_count`
- `v01_v02_conflict_count`
- `v01_v02_conflict_rate`

3. 日报增强
- `v02_top_symbols`
- `v02_top_rules`
- `v02_anomaly_notes`（可选）

> 注：字段名可在实施前统一评审，不要求完全按本草案命名。

## 4. 前端改造计划（后续）

### 4.1 Stats 页面

- 新增 v0.2 卡片区：
  - 建议发送总数 / 建议发送率
  - 方向分布
  - 置信度分布
- 新增对照区：
  - v0.1 vs v0.2 差异/冲突统计

### 4.2 Daily 页面

- 在现有 markdown 上方增加“v0.2 摘要卡片”
- 增加方向与置信度日统计概览
- 保留原 Markdown 复制能力

## 5. 实施顺序（建议）

1. 后端先补字段与接口样例
2. 前端先做 Stats 页（结构化数据更稳定）
3. 再做 Daily 页增强
4. 最后补联调验收记录与截图

## 6. 验收标准（后续）

- Stats / Daily 均可展示 v0.2 核心指标
- v0.2 指标与原始接口数据一致
- 不影响现有页面可用性
- 旧数据缺失场景不崩溃
